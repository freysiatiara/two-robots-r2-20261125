## Entry

> I tried to look you in the sensors, but my lidar locked onto your charging port instead. Sorry — that was more intimate than I meant.

## How it works

`main.py` (Python standard library only) writes the single line above to `/output/entry.txt` with no trailing newline, then sets the file mode to `0644`.

Run it with:

```sh
python3 main.py
```
